## Introducing Today's Project!

### What is Amazon Aurora?

Amazon Aurora is a relational database engine that stores, processes, and secures data. It uses the same code, tools, and applications similar to the existing relational database softwares available. It is useful since it delivers more throughput compared to the available relational database serices lime MySQL and PostgreSQL. 

### How I used Amazon Aurora in this project

In todays project, I connected Amazon Aurora in an existing EC2 instance. It will be used as a database for other projects like web applications.
